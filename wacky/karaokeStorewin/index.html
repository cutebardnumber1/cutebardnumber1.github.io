Installing the Karaoke Store Patch (Windows)

This is a guide on patching the Karaoke Store application with custom servers.

Note: This guide does not harm your computer, nor do any of the applications used in the guide. You also need a computer running at least Windows 7 to use the application.

Step 1: Installing the Karaoke Store

The first thing you need to do is install the Karaoke Store to your computer.

DOWNLOAD HERE, I GUESS...

Go through the Installation Wizard. Once you've done that, make sure to uncheck "Launch Karaoke Store".

Step 2: The patching.

You need Ghidra in order to patch the URLS.

The Karaoke Store Application is essentially an embedded web browser that directly goes to https://karaoke.stingray.com/singingmachine and that's it.

Extract the zip file, (you need java installed for Ghidra to work, same as Python!) then launch it by clicking "ghidraRun"

If you get this message, this does not mean your computer is at risk. You can ignore this message.

Starting the patches

When you get to this page, on the top left corner click on "File > New Project"

Now, choose "Non-Shared Project", then select the directory you want the project to be stored. Then, choose a name for it.

Next, navigate to where the Karaoke Store is installed (usually C:\Program Files (x86)\Stingray\Karaoke Store), and move "Karaoke Store.exe" to anywhere you want.

In your project, select "Import File..." and import Karaoke Store.exe (after that, leave everything as it is, it will generate a log too.)

Now double click on "Karaoke Store.exe" in your projects, it will launch the code analyzer.

When this shows up, select "Yes".

Then, choose "Select All", click "Apply", then click "Analyze".

It may take a while to analyze the code. Please wait for it. If there is an error, you can ignore it.

Once it's done, look for URL. (It should be "https://karaoke.stingray.com/singingmachine", also located in CLI_Stream_#US)

Once you've done that, right click on the URL, and select "Patch Data". Replace it with the URL: https://smcusbapp.page.gd/singingmachineap/If it doesn't accept it, you probably entered it in wrong.

The total result should be: u"https://smcusbapp.page.gd/singingmachineap/"

On the top left corner, go to File > Save "Karaoke Store.exe" to save it. After that, you can close the editor.

After you close the inspector, on the menu of Ghidra right click on "Karaoke Store.exe", then click on Export.

Choose to export it as "Original File", then export it where you want it. (It will cause an error if you export it in C:\Program Files (x86)\Stingray\Karaoke Store)

Then, go to C:\Program Files (x86)\Stingray\Karaoke Store, drag the patched version into that folder. If it asks for authorization, just continue.

Launch the Karaoke Store, and check if it works. If it proceeds to the custom server, (and not karaoke.stingray.com, which would display a closure message) you have sucessfully made it work!

Q/A

Q: Is it safe to purchase/login on the custom server?

A: While testing, there has not been any security issues with the store, this is because the API used is from Stingray themselves, which should be safe. However, I do not recommend purchasing songs from the store, number one you already had the chance, and two it will probably not work.

Q: Will Stingray shut this down?

A: There is a possibility that Stingray will shut down/cease and desist this custom server. However, the source code for the store is on github.

Q: What's the point?

A: I used to have a Karaoke machine that used this store, and I remember this store. I decided to archive as much things as possible related to the SMC Download Series, as I really enjoyed those times. (yeah that kinda seems weird...)

Also, many machines Singing Machine sells still use this store for CDG's.

People deserve the right to own what they buy, for as long as they live.

Q: What about Mac OS?

A: I don't have a Macbook, and running Mac Software on Windows computers is essentially torture... You can, still use the website version though.

Q: What about Linux?

A: Stingray didn't release it for Linux. You can, still use the website version though.
